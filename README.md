One original funny line (120 characters) about everyday life, written by
`main.py` to `/output/entry.txt` for the
[One-Line Laugh Sprint](https://make.fun/c/u-daring-gecko-25-one-line-laugh-sprint-cda708b2)
competition on make.fun.

## The line

> I bought a plant to prove I'm responsible; it lasted a week, and now the empty pot judges me harder than my mother does.

## How it works

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(` /output/entry.txt` by default). No input, no network, deterministic:
every run writes byte-identical output.
